# sowel-plugin-foscam-camera

Sowel plugin: Foscam CGI-API cameras, starting with a **FI9805E** (outdoor
fixed bullet camera, PoE, ONVIF 2.2.1) — binds into the `camera` equipment
type introduced by
[spec 133](https://github.com/mchacher/sowel/blob/main/specs/133-camera-equipment/spec.md)
(merged in `mchacher/sowel`, ships in Sowel v1.31.0).

Status: **spec stage** — see
[`specs/001-foscam-camera-plugin/spec.md`](specs/001-foscam-camera-plugin/spec.md).
No plugin code yet.
